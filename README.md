# Fynn & Molly

Eine kleine KI-Musikvideoserie über Fynn (Australian Shepherd, Geige) und Molly (Golden Retriever, keltische Harfe).

Website: GitHub Pages aus dem Branch `main`.

**Neue Folge hinzufügen:** Video nach `videos/folge-N.mp4`, Standbild nach `thumbs/folge-N.jpg`, dann in `index.html` im Array `episodes` den Eintrag ergänzen bzw. `video`, `thumb` und `duration` beim „Bald"-Eintrag nachtragen.
